# 中药饮片报价系统

面向中药饮片销售员的报价协作系统。MVP 由一个微信小程序和厂家外部 H5 组成，覆盖医院采购单录入、厂家本次报价、销售计价、报价版本与 Excel/PDF 导出。

## 可点击原型

直接打开 [`prototype/index.html`](prototype/index.html) 即可使用，无需安装依赖或启动服务。

原型包含三个可切换场景：

- 销售员微信小程序。
- 医院采购员轻量端。
- 厂家本次报价 H5。

原型数据保存在浏览器当前页面内，刷新后自动重置。
