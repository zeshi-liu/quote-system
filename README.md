## 可点击原型

现有原型对应 2026-07-16 的原始 v2.1，仅演示原报价流程，尚未包含本次修订新增的销售 PC、历史订单档案、回款和分析页面。

直接打开 [`prototype/index.html`](prototype/index.html) 即可使用，无需安装依赖或启动服务。

原型包含三个可切换场景：

- 销售员微信小程序。
- 医院采购员轻量端。
- 厂家本次报价 H5。

原型数据保存在浏览器当前页面内，刷新后自动重置。
