## 补充：7.8 医院历史参考的商品身份匹配

沿用每张采购根单先选一个有效代表版本（最终确认优先，否则最近有效发送），再匹配代表版的冻结行与该采购行保留的商品 ID。绑定规格时优先同规格 ID + kg，其次同标准商品 ID + 规格规范化文本 + kg，再按同标准商品 ID 降级补齐；只绑定商品时从第二级开始。无商品绑定继续品名及规格文本精确匹配 + kg。同一代表版仅展示其最佳级别的全部同行；全局按级别、发送时间倒序及稳定键排序，最多 3 张根单，不回退该单旧报价。接口逐条返回真实匹配级别、历史单位、规格/单位差异；两端明确标示降级，单位不一致时不计算差额/比例，绝不回填本次价格。
