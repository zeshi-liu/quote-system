# 报价交付闭环试用说明

2026-10-23，基于 PRD v3 与已确认设计继续开发；不依赖 AppID 的部分先交付。第一批采购/询价/计价工程已合并 PR #1，本批位于 `codex/quote-delivery`。

## 本批实现

- 销售小程序/H5 可预览全部采购行、公开备注、缺货和有效期，生成真实中文 PDF / XLSX。
- 首次受理只占用草稿，成功绑定文件才冻结内容；两格式共用原快照，失效历史文件仍可查阅。
- PostgreSQL 持久队列，独立 worker；全局同一时刻一项重任务，5 分钟执行租约、10 分钟原始总期限、最多 3 次暂错尝试（30/120 秒加抖动），代次栅栏阻止迟到绑定。
- 手工登记医院文件发送渠道；登记真实确认时间、录入时间及补录原因。并发只能形成一个最终版本和一笔订单应收；其余未发送版本作废。
- 全缺货总额为“不适用（全部缺货）”，确认知悉后完成，不建应收。含价格且合法金额舍入为 0.00 时保留零余额应收。
- 当前报价作废后可创建新版本，旧版保持作废；旧采购修订与完成订单只读。
- 私有 COS 适配、显式非生产本地存储、5 分钟下载授权、文件回读哈希、旧未绑定对象清理。

尚未实施本批之外的回款登记/调整、历史纸单补录、统计图表、OCR、完整 PC/管理员端及提醒发送；已确认需求继续保留。医院确认目前由销售录入，不冒充医院在线确认。

## 启动与存储

沿用第一批 Node 24 / pnpm 11.25.0 和数据库配置。数据库使用增量迁移 002，不修改 001。API 与 worker 必须使用同一数据库、同一存储配置。新建本机忽略文件 `.local/export.env`：

```sh
FILE_STORAGE_DRIVER=local
FILE_STORAGE_LOCAL_DIR=/ABSOLUTE/PROJECT/.local/exports
```

将绝对路径替换为实际项目路径。分别在 API、worker 终端的仓库根目录加载：

```sh
set -a
source .local/trial.env
source .local/export.env
set +a
```

之后分别运行 `pnpm dev:api`、`pnpm dev:worker`，前端仍运行 `pnpm dev:mobile-web` / `pnpm dev:supplier`。本地存储、PGlite 和试用密码仅非生产可用；未显式配置存储时不得把文件视为已生成。编译后独立 worker 用 `pnpm start:worker`，无需启动 TypeScript 运行时。

生产选 `FILE_STORAGE_DRIVER=cos` 并在服务端配置 `COS_SECRET_ID`、`COS_SECRET_KEY`、`COS_BUCKET`、`COS_REGION`。桶必须私有；IAM 仅授予本应用所需对象前缀权限，H5 跨域下载须给实际前端来源配置 COS CORS GET。签名授权 5 分钟，已签发链接在短有效期内可能仍可使用。凭证和签名 URL 不提交仓库、不写业务回执或日志。

生产还须配置真实 `QUOTE_SELLER_NAME`、`QUOTE_CONTACT`；`QUOTE_NOTES` 为可选固定说明。含税文案固定“以上报价均为含税价格”。中文字体用有授权的 `EXPORT_FONT_PATH` 与集合字体 `EXPORT_FONT_FAMILY`，建议部署 Noto CJK；Mac 字体 fallback 只用于本地开发，不随项目分发。已有导出快照不随模板环境变量变化。

`deploy/worker-compose.yaml` 是 worker 服务片段，含 1 GiB 容器上限、0.75 CPU、只读应用/字体及进程限制；需要和实际 API、数据库、网络方案组合，并在腾讯云演练。子进程堆上限 512 MiB，Linux 另监测 RSS，执行超时强制退出；不能用本机测试声称云端资源限额已验收。

本机文档保护软件会给落盘的 `.pdf/.xlsx` 加包装，回读字节因此改变。渲染内存字节可解析，服务端上传后回读 SHA 会拒绝这类对象并保持草稿；不修改本机安全软件、不以改文件后缀绕过保护。本机文件持久存储下载验收尚未通过，须在获准的正常文件系统或真实私有 COS 上核验。

## 检查与试用

```sh
pnpm test:offline
pnpm test:ui
pnpm typecheck
pnpm build
```

原生 PostgreSQL CI 使用专用 `quote_core_test` 随机 schema；本机 PGlite 仅用于离线功能。CI 必须配置中文字体，工作流已安装 Noto CJK 和 Poppler。正常跨午夜且未到有效期的导出可成功，保留准备快照日期；跨医院或基准实际有效期、总期限或失去占用的绑定会失败。

浏览器步骤：保存计价→报价交付→选择 PDF/Excel→先看到“排队/生成”→刷新至成功→下载→自行发送后登记渠道→填写实际确认时间→复核总额并确认。另试全缺货、占用时刷新、旧版查看、重询、作废后创建新草稿，以及响应丢失后的原请求核对。
